# P1 Chat Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Stream chat completions from an OpenAI-compatible endpoint with cancel, persistence, clipboard/file context, and first-token telemetry — without loading the LLM stack on cold start.

**Architecture:** `LLMClient` actor (lazy-created on first send) + `SettingsStore` (UserDefaults + Keychain). `ChatViewModel` coalesces tokens every 30ms. `SessionStore` persists messages with optional file-backed bodies.

**Tech Stack:** Swift 5.10+, URLSession streaming, SQLite, Keychain

## Global Constraints

- Placeholder assistant row ≤ 100ms after send
- First-token feel ≤ 300ms (recorded via `firstToken` telemetry)
- No LLM imports on app launch path
- OpenAI-compatible HTTP only; no vendor SDK
- Message bodies > 32KB stored as files

## Delivered in this branch

- `Packages/LLMClient` — SSE streaming, cancel
- `Packages/SettingsStore` — base URL, model, API key
- `SessionStore` — fetch/update messages, session touch
- `ChatViewModel` + message UI, send/cancel, paste/drop context
- Settings → model configuration (default Ollama local URL)

## P1 gate verification

1. Build: `swift build --package-path Apps/MacBuddy`
2. Run app: `bash Scripts/build_app.sh && open Apps/MacBuddy/build/Debug/MacBuddy.app`
3. Settings → set base URL + model (Ollama/OpenAI-compatible)
4. Send message → see streaming reply; Cancel mid-stream works
5. Check Performance tab for `firstToken` events after sends
