# 从零拆解：六个 AI 产品（傻瓜讲解）

这几份是**教学拆解**，根据公开资料写成，不是各公司的内部设计文档。目标是：就算你几乎没做过这类产品，也能看懂他们在想什么、系统怎么一块块拼起来、你自己最小能做出哪一截。

先读本页，再按兴趣打开单篇。建议顺序：先看 Cursor 和 Codex 建立「循环 + 外壳」的直觉，再看 WorkBuddy / Qoder 对照办公 vs 编程，最后看 DeepSeek Harness（可插拔底盘）和 Unsloth（模型怎么在你电脑上训练/跑）。每篇都有「第 0 周最小版」，从那一节动手即可。

## 六份里反复出现的同一口锅

所有「能自己读文件、改文件、跑命令」的助手，内核都是这一圈：

1. 人说一句话  
2. 程序把「现在环境」塞进模型（打开的文件、检索到的代码、规则）  
3. 模型要么直接回答，要么说「请帮我调用某某工具」  
4. 程序去真实世界执行（读盘、改文件、跑测试）  
5. 把结果再喂回模型  
6. 重复，直到完成或等人点头  

差别只在：外壳是编辑器还是菜单栏、工具允许多危险、上下文从哪来。

Unsloth **不走这口锅**。它解决的是「模型怎么在你的显卡/苹果芯片上训练得动、跑得动」。

## 和 MacBuddy 的关系

MacBuddy 更接近「薄壳 + 按需引擎」，哲学上像 Codex / DeepSeek Harness，产品形态上像缩小的 WorkBuddy（工作）加上缩小的 Cursor（补丁预览），但**不要**去复刻整套 IDE 或腾讯办公生态。

## 诚实的预期

「从零开发出来」指的是做出**同类最小系统**（能聊天、能调工具、能改一个文件）。Cursor / Qoder 那种完整 IDE 是多年、多人、大量模型和基础设施堆出来的。文中会写「第 0 周最小版」和「他们现在多出来的部分」，避免你一上来就想造航母。
